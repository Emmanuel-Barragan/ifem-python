# ifem-python
A Python translation of the Mathematica code examples from Felippa's *Introduction to the Finite Element Method*. 

The aim is to mirror Felippa's original as closely as possible, so that it can be read alongside the book.

I understand the benefits of using Computer Algebra Systems like Mathematica, especially given the symbolic computation capabilities. Nonetheless, I still prefer the structure and clarity of Python, which is why I'm writing this.

The files are divided by chapter. Any chapter that is specifically devoted to a computational implementation will get a file here. Likewise, each file is self-contained.  

Of course, full credit to the original work by Professor Felippa. *IFEM* is a brilliant book, and it's worth a thourough read.
